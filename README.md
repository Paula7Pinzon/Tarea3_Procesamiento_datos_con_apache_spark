# Procesamiento en Batch con Apache Spark

## Descripción
Este proyecto implementa procesamiento de datos en batch usando Apache Spark.

Se utiliza un dataset de salud mental en adolescentes para análisis exploratorio.

## Procesos realizados
- Carga de datos CSV
- Exploración de datos
- Limpieza de datos
- Análisis (conteo por género y promedio de edad)
- Almacenamiento de resultados

## Ejecución

```bash
spark-submit batch_processing.py
